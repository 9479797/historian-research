# historian-research
История России XIX — начала XX века: источники и анализ событий

## Методика исследования

- [Historian](skills/historian/SKILL.md) — проверка происхождения источников, оценка свидетельств и разбор расхождений.
- [Historian Analyst](skills/historian-analyst/SKILL.md) — разбор причин, сравнение событий и оценка исторических объяснений.

В папке [`optional-methods/`](optional-methods/) хранятся основные версии трёх необязательных методик. Копии входят в `references/optional-methods/` каждого скилла, поэтому доступны при установке одной папки. При правке методики обнови обе копии. Чтобы исключить методику из обоих скиллов, удали основной файл, обе копии и соответствующий пункт из двух `SKILL.md`.

## Работа с навыками через ChatGPT

**Для работы через подключённый GitHub оба навыка могут оставаться только в этом репозитории.** Локальная копия на Mac полезна, если навыки запускаются через терминал, нужны локальные скрипты или требуется доступ к файлам компьютера, но для моей работы с методиками она не обязательна.

При запросе о достоверности исторического факта или источника используется [Historian](skills/historian/SKILL.md), а при анализе причин событий — [Historian Analyst](skills/historian-analyst/SKILL.md). При комплексном вопросе сначала проверяются свидетельства, затем объяснения.

**Важно:** GitHub хранит инструкции, но сам по себе не включает их автоматически во всех разговорах. Ассистент открывает нужную версию навыка и его справочники по текущей задаче. Файлы, которые есть только на Mac или в личном архиве, нужно отдельно предоставить или подключить через доступное хранилище.

Правила дальнейшей разработки, сохранения методик и обращения с источниками — в [AGENTS.md](AGENTS.md). Существующие навыки и дополнительные методики остаются без изменений.

## Автоматические уведомления и синхронизация Mac

GitHub Actions [check-upstreams.yml](.github/workflows/check-upstreams.yml) еженедельно проверяет изменения именно в папках двух оригинальных навыков. При обновлении создаётся GitHub Issue с упоминанием и назначением владельцу; изменения сторонних разработчиков **не сливаются автоматически**. Чтобы получать уведомления, настрой уведомления GitHub об упоминаниях и назначениях.

Для **автоматической синхронизации двух своих репозиториев** на Mac один раз установи пользовательский планировщик (без `sudo`):

```bash
cd "$HOME/Мак-Документы/Гитхаб+Клод/historian-research"
git pull --ff-only origin main
bash scripts/install-macos-sync.sh
```

После установки Mac проверяет обновления при входе в систему и каждый день в **11:20 по локальному времени Mac**. Обновляются только чистые ветки `main` репозиториев `historian-research` и `ex-ussr-kinship-research`, только из `9479797`, только через fast-forward. При конфликте или локальных изменениях обновление пропускается. При успешном обновлении показывается системное уведомление. Список проблем — `~/Library/Logs/history-skills-sync.log`.

Проверить вручную:

```bash
bash scripts/sync-macos.sh
tail -n 50 "$HOME/Library/Logs/history-skills-sync.log"
```

Отключить ежедневные проверки:

```bash
bash scripts/install-macos-sync.sh --uninstall
```

Это **не обновляет автоматически локальные установки навыков** в `~/.claude/skills` или `~/.agents/skills`. При использовании Claude Code нужно убедиться, что он читает актуальные проектные папки.
