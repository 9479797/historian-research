# historian-research
История России XIX — начала XX века: источники и анализ событий

## Методика исследования

- [Historian](skills/historian/SKILL.md) — проверка происхождения источников, оценка свидетельств и разбор расхождений.
- [Historian Analyst](skills/historian-analyst/SKILL.md) — разбор причин, сравнение событий и оценка исторических объяснений.

В папке [`optional-methods/`](optional-methods/) хранятся основные версии трёх необязательных методик. Копии входят в `references/optional-methods/` каждого скилла, поэтому доступны при установке одной папки. При правке методики обнови обе копии. Чтобы исключить методику из обоих скиллов, удали основной файл, обе копии и соответствующий пункт из двух `SKILL.md`.
