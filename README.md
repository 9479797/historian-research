# historian-research
История России XIX — начала XX века: источники и анализ событий

## Методика исследования

- [Historian](skills/historian/SKILL.md) — проверка происхождения источников, оценка свидетельств и разбор расхождений.
- [Historian Analyst](skills/historian-analyst/SKILL.md) — разбор причин, сравнение событий и оценка исторических объяснений.

В папке [`optional-methods/`](optional-methods/) лежат необязательные рабочие материалы. Каждый файл можно применять и удалять отдельно. Ссылка на исходную методику указана в самом файле.
