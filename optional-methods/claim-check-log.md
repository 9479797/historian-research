# Журнал проверки утверждений

**Необязательное дополнение.** Использовать при проверке готового текста, справки или чернового вывода. На каждый проверяемый тезис заводится отдельная запись.

Источник методики — [Jamditis, Fact-check workflow](https://github.com/jamditis/claude-skills-journalism/blob/a6383bd0c4cb22cc04056875f4d50603489b003b/journalism-core/skills/fact-check-workflow/SKILL.md). Шаблон адаптирован для исторических исследований.

## Запись для одного утверждения

- **Тезис.** Точная цитата из черновика и место, где она стоит. Если в предложении несколько проверяемых утверждений, разнести их по записям.
- **В каком смысле проверяем.** Уточнить действующее лицо, место, период, значение спорного слова. Для дат указать календарный стиль, если он влияет на сверку.
- **Доказательства.** Для каждого источника записать, что именно он подтверждает или ставит под сомнение. Указать ссылку и страницу либо архив, фонд, опись, дело и лист. Отметить, просмотрен ли документ, его публикация или только описание в каталоге.
- **Результат.** Подтверждено / подтверждено частично / опровергнуто / доступных свидетельств пока недостаточно. Объяснить, на чём держится вывод и какие сведения ограничивают его.
- **Дальнейшее действие.** Оставить формулировку, уточнить её, удалить или указать конкретный документ, который ещё нужно посмотреть.

Если опись указывает на интересующее дело, зафиксировать его шифр как зацепку для поиска. При оценке тезиса учитывать только то, что удалось прочитать и сверить.
